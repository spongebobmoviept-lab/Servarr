Connect Discord

The bot token that lets Servarr actually run in your server.

Where do I get a bot token?
  1. Go to the Discord Developer Portal → New Application.
  2. Bot tab → Reset Token → copy it (you won't see it again).
  3. Under Privileged Gateway Intents, turn on Message Content Intent and Server Members Intent — Servarr needs both.
  4. OAuth2 → URL Generator: check bot and applications.commands, pick the permissions it needs, then open the generated URL to invite it to your server.
  5. Enable Developer Mode in Discord (User Settings → Advanced), then right-click your server icon → Copy Server ID for the guild ID above.

How do I find my Plex token?
  1. Open Plex Web, start playing anything.
  2. Player's ⋯ menu → Get Info → View XML (bottom-left).
  3. Look at the new tab's address bar for X-Plex-Token=....
