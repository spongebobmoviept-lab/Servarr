Where do I get a bot token?
  1. Go to the Discord Developer Portal → New Application.
  2. Bot tab → Reset Token → copy it (you won't see it again).

Connect your Discord bot

Paste the bot's token. Servarr keeps it in its own data folder, readable by the app only, and never shows it again.

Where do I get a bot token?
  1. Open the Discord Developer Portal (discord.com/developers/applications) → New Application, and name it, e.g. "Movie Night".
  2. Bot tab → Reset Token → copy it (you won't see it again).
  3. Optional: under Privileged Gateway Intents, turn on Server Members Intent, so DJs get their private player link by DM at showtime. Nothing else is needed; in this mode the bot never reads messages.

Invite the bot to your server

Open the link, pick your server, and click Authorize. You need Manage Server there; otherwise send the link to someone who has it.

Open the invite link

It asks only for what Movie Night uses: View Channels, Send Messages, Embed Links, Read Message History, plus slash commands. No admin, moderation or message-reading access.
